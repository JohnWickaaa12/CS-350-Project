# CS 350 – Emerging Systems Architectures and Technologies

## Project Reflection

Throughout CS 350, I worked with a Raspberry Pi to learn how software and hardware communicate with each other. For my portfolio, I chose my Smart Thermostat project and my Morse Code LED project because I feel like these two projects show the skills I developed throughout the course.

**Summarize the project and what problem it was solving.**

The Smart Thermostat project involved creating a working thermostat prototype using a Raspberry Pi, temperature sensor, LCD display, and buttons. The goal was to create a system that could monitor temperature and allow the user to control thermostat settings. My Morse Code project involved programming red and blue LEDs to blink different messages using a state machine and buttons. Both projects helped me understand how software can control physical components and respond to user input.

**What did you do particularly well?**

I think one thing I did well was troubleshooting problems when something wasn't working correctly. Throughout the course, I ran into issues with wiring, getting the LCD to display information correctly, and making sure the buttons responded properly. Instead of changing everything at once, I learned to test individual components to figure out what was causing the problem. I also became more comfortable using Python and VS Code to write and test code directly on my Raspberry Pi.

**Where could you improve?**

One area I could improve is planning out my code and hardware connections before starting a project. Sometimes I spent more time troubleshooting than I expected because I was still learning how the different components worked together. I also want to improve how I organize my code and handle errors so that future projects are easier to maintain and troubleshoot.

**What tools and/or resources are you adding to your support network?**

Some of the most useful tools I worked with were Raspberry Pi, Python, VS Code, and GitHub. I also learned how to connect to my Raspberry Pi remotely using SSH, which made working on projects easier. The Raspberry Pi documentation, Python documentation, and Adafruit libraries were helpful resources when learning how to work with sensors and displays. These are tools and resources I plan to continue using as I work on other programming projects.

**What skills from this project will be particularly transferable to other projects and/or coursework?**

The biggest skills I gained were troubleshooting, Python programming, working with hardware, and understanding how different components communicate. I also gained experience with state machines, GPIO pins, sensors, and user input. Even though I am pursuing software engineering, I think understanding how software interacts with hardware will be useful in other areas of development. Learning how to break down problems and test individual parts of a system is something I can apply to almost any programming project.

**How did you make this project maintainable, readable, and adaptable?**

I worked on keeping my code organized by separating different functions and using variables to make changes easier. I also used comments to explain important parts of the code so it would be easier to understand later. For the thermostat project, separating the button controls, temperature readings, and display updates helped make the program easier to troubleshoot. This also makes it easier to add features or change components in the future without having to rewrite the entire program.

## Conclusion

Overall, CS 350 helped me gain a better understanding of how software and hardware work together. Before this course, I didn't have much experience working directly with a Raspberry Pi or building circuits. By the end of the course, I was able to connect multiple components and write Python programs to control them. I still have a lot to learn, but I feel more confident troubleshooting problems and working with technologies I haven't used before.
